Настройки сайта

Включает или выключает все WebGL-сцены: первый экран, этапы доставки, глобус и финальный блок. Вместо выключенных сцен показываются фотографии. Код 3D остаётся в проекте.

3D-сцены в этом браузере

Панели настройки изображений

Панель «Изображения» появляется в правом верхнем углу сайта и работает только в режиме разработки (npm run dev). На опубликованном сайте её нет.

Открыть сайт в выбранном режиме →

Чтобы выключить 3D для всех посетителей

Этот переключатель действует только в текущем браузере. Для всех посетителей поменяйте одну строку в src/siteConfig.js:

export const SCENES_MODE='images';

Значение '3d' снова включает сцены.
