# КАСТОМС ЛИДЕР

Локальный лендинг на React, Vite и Three.js. Публикация не выполнялась.

```sh
npm install
npm run dev -- --port 5173
npm run build
```

Предпросмотр: http://127.0.0.1:5173/. Production-файлы — `dist/`.

## Публикация

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует его в GitHub Pages после отправки изменений в ветку `main`. Vite автоматически задаёт путь проектной страницы на GitHub; источник Pages в настройках репозитория должен быть выбран как **GitHub Actions**.

## Содержание

`landing-structure.md` — исходный документ, не изменён. `scripts/extract-content.py` извлекает заголовки, услуги, кейсы, табы и FAQ в `src/content.json`. Выполнить после правок документа: `python3 scripts/extract-content.py`. Остальные тексты и формы находятся в `src/App.jsx`.

Исходные факты и порядок разделов сохранены. Norda, 700 т, 160 м, 6 800 км, вымышленные температуры и новые слоганы не добавлены. Широкий экран: вступительная сцена закрепляется на время смены шести грузов. Мобильная версия: обычная прокрутка. Анимацию можно остановить кнопкой справа внизу; учитывается prefers-reduced-motion. WebGL загружается по мере приближения к сцене; вне экрана рендер останавливается.

## До запуска

- Все формы работают в локальном режиме: проверяют поля и честно сообщают, что отправка не подключена. Контакты в формах не сохраняются и не отправляются.
- `server/bitrix24.mjs` — неподключённый серверный адаптер. Перед подключением проверить поля в конкретном портале Bitrix24. Создать серверный обработчик, ограничить частоту и размер запросов, валидировать origin и входные поля. Секрет хранить только в серверной переменной `BITRIX24_WEBHOOK_URL`. Возвращать `{ "ok": true }` только после успеха CRM. Путь обработчика указать в `VITE_LEAD_ENDPOINT`. В браузер webhook не передавать.
- Реальные фото, логотип, PDF компании, ссылки мессенджеров и юридические документы не предоставлены. Основатель — явный плейсхолдер; остальные изображения — авторские геометрические 3D-иллюстрации, а не фотографии проектов. Для отсутствующих ссылок предусмотрены сообщения.
- Политика, оферта и согласие показывают статус отсутствующего документа, а не неподтверждённый юридический текст. Cookie-уведомление сообщает о сохранении настроек; аналитика отсутствует.
- Уточнить имена клиентов во 2-м и 3-м кейсах, повторяющееся описание преимущества и условия страхования — как указано в исходном документе.

## Аналитика и SEO

Title, description, lang, viewport, один H1 и последовательная семантика уже предусмотрены. После выбора домена добавить canonical, robots.txt и sitemap.xml. Реальные фотографии снабдить содержательными alt. Проверить индексируемую HTML-версию при публикации (сейчас React SPA; для поисковой выдачи и GEO рекомендуется prerender/SSR). Структурированные данные Organization/Service добавлять только по подтверждённым реквизитам и услугам.

После согласования режима аналитики подключить Яндекс Метрику. Событие `lead:success` возникает только при успешном ответе подключённого сервера; отправлять цель без персональных данных. Отдельно добавить цели для `tel:` / `mailto:` и действующих мессенджеров. Не считать локальное сообщение отправленной заявкой.

## Источники ресурсов

- Golos Text, Google Fonts: WOFF2 для сайта и исходные TTF в `src/assets/fonts/`; лицензия SIL Open Font License (`src/assets/fonts/OFL.txt`).
- Natural Earth, `ne_110m_land.geojson`, public domain; локальная основа контуров глобуса из репозитория nvkelso/natural-earth-vector.
- Lucide — ISC; иконки из установленного пакета.
- Все 3D-модели построены кодом в `src/Scene.js`; внешних моделей и фотографий нет.
